1. Set up your first vault

  1. Open PatternVault and continue through, or skip, the introduction. Choose Create a new vault. If you already have a backup or an invitation, choose the restore or join option instead.
  2. Choose a 3 × 3, 4 × 4, or 5 × 5 grid and name the vault.
  3. Draw a pattern using at least four different dots, then repeat it. Dots crossed along the path are included automatically; a dot cannot be used twice in one gesture.
  4. Use a generated 20-word recovery phrase, or create a custom phrase with at least eight words and 40 characters. Save it outside PatternVault with Save to Notes or Copy phrase.
  5. Repeat the full phrase and confirm that you saved it outside the app. You can close the purchase offers and continue with the free version.
Keep the phrase somewhere you can reach without this device. A phrase stored only inside the vault cannot help you if that vault is unavailable. Switching apps during first-time setup preserves unfinished steps in memory; ending the app process can discard unfinished setup.

The app supports iPhone and iPad on iOS/iPadOS 26.2 or later. Interface labels follow the selected app language.

2. Open and switch vaults

Each pattern selects a different vault. From the library header, tap New vault, enter a name, and draw a new pattern twice. You cannot reuse a pattern already assigned to another vault. An unknown pattern never creates a vault automatically.

Tap the lock icon to return to the lock screen, then draw the other vault’s pattern. PatternVault also locks after going into the background. A folder organizes items inside a vault; it does not have its own pattern or separate storage allowance.

The free version includes three owned vaults with five items each. Photos, videos, memos, and documents all count; items inside folders share the same allowance.

3. Add photos, videos, memos, and documents

Open the destination vault and, optionally, a folder. Tap Add:

  • Media: select photos or videos in the system picker. PatternVault copies the selected items and reports any failures or skipped items.
  • Memo: write a title and text, then save. Memos are stored as text files.
  • Document: select files from Files or an available file provider. PatternVault makes its own copies. Some formats can be stored even when a preview is unavailable.
  • Camera: capture a new photo or video directly into a private draft.

Imports do not automatically remove source files. After a successful Photos import, Delete originals from Photos is optional and requires permission and system confirmation. It affects the Photos library, including iCloud Photos and synced devices when enabled. Photos may keep deleted items in Recently Deleted. PatternVault does not empty that collection.

The current Live Photo import saves its still image, not the motion component; PatternVault declines automatic deletion of those Live Photo originals. Verify important imports before deleting sources.

4. Use the private camera

  1. Choose Add → Camera and allow camera access. Microphone access is requested for video recording.
  2. Choose Photo or Video and use the front/rear camera control as needed.
  3. In Photo mode, tap the speaker control next to the camera switch. A crossed-out speaker selects silent photo capture on supported cameras.
  4. Capture, then review. Choose Use to save into the current vault/folder, or Retake to discard the draft and return to the camera. Cancel or backgrounding discards an unconfirmed capture.

Captures are not automatically added to Photos. Silent photos use a camera video frame and can have less detail than normal photos; support depends on the device and camera. The speaker setting does not mute audio in recorded videos. The camera review uses its own dark appearance.

5. Search, filter, and organize

  • Search: enter part of an item or filename in the search field. Search works within the current library or folder, combines with the selected filter, and is not a search of text inside a document. Folder changes or adding content clear the search.
  • Sort: tap the up/down-arrow icon. Choose import date, name, file date, largest first, or smallest first. File date uses available original metadata, with fallback dates when needed.
  • Filter: tap the filter icon for All, Photos, Videos, Memos, or Documents.
  • Select: tap the check-circle icon to select items, select all, move, export, or delete. Tap it again to finish selection.
  • Folders: create, rename, recolor, or delete folders using the folder controls. Move selected items into a folder. Deleting a folder keeps its items in the vault.

On wider iPad layouts, a folder sidebar provides navigation. Photos support zoom and paging; videos use native playback controls. Playback pauses when you leave a video or background the app.

6. Export and delete items

Select the items and use the export action to open the system share sheet. Choose Files, another app, or an available destination. Exports are ordinary copies of the selected files, not encrypted PatternVault backups. Their metadata may remain. For an encrypted archive, use File backup instead.

Received shared vaults can export only if the owner allows it. Deleting items removes the app’s copies after confirmation and has no in-app trash. It does not delete Photos originals or previously exported copies.

7. Patterns, recovery phrases, and grid size

Open the gear icon for Vault settings. To change a pattern, confirm the current one, then enter the new one twice. If you forgot the pattern, use Recover vault on the lock screen and supply that vault’s recovery phrase to choose a replacement. Repeated incorrect attempts cause a cooldown.

To generate or replace a recovery phrase, use the Recovery section, save the new phrase externally, repeat it, and confirm the current pattern. Generated phrases are recommended. A replacement invalidates the old phrase for local recovery immediately. For an existing iCloud backup, the change takes effect after the next backup completes; an already exported file always requires its original phrase.

Pattern grid changes the grid for every vault. Choose a size and follow the wizard for each vault: confirm its old pattern, then draw a unique new pattern twice. Biometric authentication is also required if any vault uses it. Review and save. Cancelling leaves the existing grid and patterns unchanged; a successful change locks open vault windows.

Recovery is not a backup. Resetting a pattern helps open files still on the device. Recovering deleted files requires a saved backup as well as the correct phrase.

8. Back up to iCloud

  1. Open the owned vault, then Settings → Encrypted iCloud backup.
  2. Enter its recovery phrase and choose Enable iCloud backup.
  3. Keep the vault open with internet access and enough iCloud storage. Wait for a Last completed backup date.
  4. Use Back up now for a fresh copy before switching devices or removing the app. Reopen the vault to retry an interrupted upload.

Each vault opts in separately. The app keeps one latest completed cloud backup, without historical versions. Backups run in the foreground; this is not two-way sync between your devices.

Turn off and delete cloud backup stops future backup and requests removal of that configured cloud copy. Your local files remain. If removal is pending, reconnect with the same iCloud account and let the app retry.

9. Restore from iCloud

  1. Sign in to the Apple Account that owns the backup.
  2. Choose Restore from iCloud during onboarding, on the lock screen, or in backup settings.
  3. Choose a dated backup and enter the phrase valid for its latest completed upload.
  4. Open the backup, choose a unique local vault name, and set a new pattern.
  5. After restoration, set up a new recovery phrase and enable future backup again if desired.

Restoration creates a new vault and does not overwrite another one. Names are encrypted, so the initial list identifies backups by date. Free limits are checked before installation; an oversized backup is not silently truncated.

A pattern alone cannot restore deleted media. A recovery phrase without a completed backup cannot recreate it either.

10. Export or import an encrypted backup file

For a portable archive, open Settings → File backup → Export backup file, enter the recovery phrase, and save the .patternbackup file through Files. Store the file and phrase separately. If you save to iCloud Drive or another cloud provider, wait for that provider’s upload to finish.

A file backup is a snapshot: export again to include later changes. To restore it, choose Import a backup file, select the archive, enter the phrase used when it was created, and follow the new-vault setup. Changing the app’s current recovery phrase does not rewrite existing archive files.

11. Share a vault or accept a share

Create a share

  1. With PatternVault Pro, open the owned vault and choose Settings → Sharing.
  2. Optionally enter a recipient label and set an expiry, maximum opens, export permission, or capture-triggered lock.
  3. Choose Create sharing phrase and wait for the upload to finish.
  4. Copy and send that phrase privately to the intended recipient. It is separate from both your pattern and recovery phrase. The phrase is not shown again after you leave its display.

Accept a share

Choose Join shared vault in onboarding, on the lock screen, or in settings. Enter the sharing phrase while signed in to iCloud, then choose a local name and pattern. The first claiming Apple Account becomes the recipient. The same account can import again using the original sharing phrase.

Receiving is free and does not consume owned-vault limits. Received vaults are read-only, require an internet connection to open, and periodically recheck access while open. Owners send updates while their vault is open; recipients receive the available version when reopening.

Control or end access

Use the owner’s Sharing settings to send updates or Revoke access. Revocation takes effect when iCloud receives it. Keep the app installed until pending revocations finish. Open limits are counted per local installation, so removal or reinstallation can reset them. Capture locking reacts to detection and cannot prevent the first screenshot or an external camera. Previously exported copies remain outside PatternVault’s control.

12. Add Face ID or Touch ID and a dummy vault

In settings, open Face ID & dummy vault or Touch ID & dummy vault. Choose another existing vault as the dummy, enable biometric protection, and follow the pattern and biometric confirmations.

Your pattern still selects the protected vault. Successful biometrics then open it; the device passcode is not a substitute. A failed, denied, cancelled, or unavailable biometric check displays the chosen dummy instead. A system interruption leaves the app locked.

A dummy session can use its media but cannot open vault settings or create vaults. Unlock the dummy with its own pattern for full access. If the dummy has been deleted, failed authentication keeps the app locked. Biometric failure does not activate duress.

13. Understand duress before enabling it

This changes access to your other vaults. Do not enable or test it on irreplaceable content without a separately saved, usable backup.

Use a duress vault arms the current vault’s existing pattern. Setup explains the consequences and requires acknowledgment and pattern confirmation. It does not trigger immediately.

On a later unlock with that armed pattern:

  • The selected dummy survives, or the triggering vault survives if no dummy is selected. When a different dummy survives, the triggering vault also loses access.
  • Credentials for every other local vault are removed. Their old patterns and recovery phrases no longer open them in PatternVault, although the files remain on disk.
  • The surviving vault gets a new recovery phrase. Use Save new recovery phrase in its settings and keep it externally.
  • Cloud backup, sharing, and manual backups stop on that installation. Owned shares are queued for revocation. Earlier personal cloud backups and separately exported backup files are not erased.

Turning duress off does not restore removed access or re-enable backups. Restoring a usable independent backup is a separate action. Confirming a pattern inside settings does not activate duress. Duress is not secure erasure or a guarantee that the app’s data cannot be discovered.

14. Change the icon or language

Open Settings → App settings → App icon and select a design. Classic restores the primary icon. The icon applies across all vaults on that device and does not change access or the installed app’s name.

For a custom launcher name, use the picker’s Home Screen name → Set up a named shortcut guide. It helps you create an Apple Shortcuts “Open App → PatternVault” launcher with selected artwork. This creates a separate shortcut; it does not rename, hide, or remove the installed app.

PatternVault supports English, Japanese, Korean, French, German, Italian, and Simplified Chinese. Change the app’s language in device Settings where available. Your own names, filenames, and phrase words are not translated.

15. Purchases, removal, and help

Open PatternVault Pro in vault settings to purchase or restore purchases. It is a one-time unlock. The regular and special-offer purchases grant the same features. Restore purchases with the original Apple Account; it does not restore vault media.

Delete this vault requires its name and current pattern. It removes its local content and credentials and, for owned vaults, requests deletion of configured cloud backup and owned shares. Other local vaults, Photos originals, and exported files remain. Removing a received vault removes only its local copy.

Deleting PatternVault removes local vaults and its installation key. Offloading keeps app data. Before deleting, verify a usable backup and complete cloud removals you want performed.
