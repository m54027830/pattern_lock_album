1. 最初の保管庫を作る

  1. PatternVaultを開き、案内を進めるかスキップして、「新しい保管庫を作成」を選びます。バックアップや招待がある場合は、復元や共有への参加を選んでください。
  2. 3 × 3、4 × 4、5 × 5からグリッドを選び、保管庫に名前を付けます。
  3. 4つ以上の異なる点を使ってパターンを描き、もう一度同じパターンを描きます。途中で通過した点は自動で含まれ、1回の操作で同じ点を再使用することはできません。
  4. 生成された20語の復旧フレーズ、または8語以上・40文字以上のカスタムフレーズを使います。「メモに保存」または「フレーズをコピー」で、PatternVaultの外に保存してください。
  5. フレーズ全体を再入力し、アプリの外に保存したことを確認します。購入オファーは閉じて、無料版で続けられます。
この端末が使えなくても取り出せる場所へ。保管庫の中にだけフレーズを保存しても、その保管庫が開けないときには役立ちません。初期設定中のアプリ切り替えでは手順をメモリ内に保持しますが、アプリのプロセスが終了すると未完了の設定が失われる場合があります。

iOS・iPadOS 26.2以降のiPhone・iPadに対応します。画面の表示名は、選択したアプリの言語によって変わります。

2. 保管庫を開く・切り替える

それぞれのパターンが、別の保管庫を開きます。ライブラリ上部の「新しい保管庫」から、名前を付けて新しいパターンを2回描いてください。他の保管庫に登録済みのパターンは使えません。未登録のパターンを入力しても、保管庫が自動作成されることはありません。

鍵のアイコンでロック画面に戻り、別の保管庫のパターンを描くと切り替わります。バックグラウンドに移動した後も再度ロックされます。フォルダは保管庫内を整理するもので、別のパターンや保存枠はありません。

無料版は所有する保管庫3つ、各5項目までです。写真・動画・メモ・書類を合算し、フォルダ内の項目も同じ上限に含まれます。

3. 写真・動画・メモ・書類を追加する

保存先の保管庫、必要に応じてフォルダを開き、「追加」を選びます。

  • メディア：システムの選択画面で写真や動画を選びます。PatternVaultがコピーを作り、失敗やスキップがあれば知らせます。
  • メモ：タイトルと本文を入力して保存します。メモはテキストファイルとして保存されます。
  • 書類：「ファイル」や利用可能なファイル提供サービスから選びます。PatternVault内にコピーします。プレビューできない形式でも保存できる場合があります。
  • カメラ：新しい写真や動画を、アプリ内の確認用下書きとして撮影します。

読み込みだけでは元のファイルを削除しません。写真の読み込みが成功した後に、任意でオリジナル削除を選べます。権限とシステムの確認が必要で、iCloud写真や同期端末にも影響する場合があります。「最近削除した項目」に残る場合もあり、PatternVaultはこの一覧を空にしません。

現在のLive Photosの読み込みは静止画のみで、動きの部分は保存しません。そのため、Live Photoのオリジナルの自動削除は行いません。大切なものは、元データを削除する前にコピーを確認してください。

4. プライベートカメラを使う

  1. 「追加 → カメラ」でカメラアクセスを許可します。動画ではマイクの許可も求められます。
  2. 写真・動画モードを選び、必要に応じて前面・背面カメラを切り替えます。
  3. 写真モードで、カメラ切り替えの横のスピーカーボタンを選びます。斜線付きのスピーカーが、対応カメラでの無音撮影です。
  4. 撮影後に内容を確認し、「使用」で現在の保管庫・フォルダに保存するか、「撮り直す」で下書きを破棄してカメラに戻ります。キャンセルやバックグラウンドへの移動でも、未確定の撮影内容を破棄します。

撮影した内容を「写真」へ自動保存しません。無音写真は動画フレームを利用するため、通常の写真より細部の画質が低くなる場合があります。端末・カメラにより対応状況が異なります。スピーカー設定は動画の録音をミュートするものではありません。撮影確認画面は固有の暗い表示を使います。

5. 検索・絞り込み・整理

  • 検索：項目名やファイル名の一部を入力します。現在のライブラリ・フォルダ内で、選択中のフィルタと組み合わせて検索します。書類の本文検索ではありません。フォルダの変更や項目の追加で検索文字はクリアされます。
  • 並べ替え：上下矢印のアイコンから、読み込み日、名前、ファイルの日付、サイズの大きい順・小さい順を選びます。ファイルの日付は、利用できる元のメタデータを優先し、なければ代替の日付を使います。
  • フィルタ：フィルタのアイコンから、すべて、写真、動画、メモ、書類を選びます。
  • 選択：丸いチェックのアイコンで項目を選び、すべて選択、移動、書き出し、削除を行います。もう一度押すと選択を終了します。
  • フォルダ：フォルダの操作メニューで作成、名前・色の変更、削除を行います。選択した項目を移動できます。フォルダを削除しても、中の項目は保管庫に残ります。

幅の広いiPadの表示では、フォルダのサイドバーを利用できます。写真は拡大やページ送り、動画は標準の再生操作に対応します。動画から離れるかバックグラウンドに移動すると再生を停止します。

6. 項目を書き出す・削除する

項目を選んで書き出しを実行すると、システムの共有シートが開きます。「ファイル」、他のアプリ、利用できる送信先を選んでください。これは選択したファイルの通常のコピーであり、暗号化されたPatternVaultバックアップではありません。メタデータが残る場合もあります。暗号化アーカイブにはファイルバックアップを使います。

受信した共有保管庫からの書き出しは、所有者が許可した場合に限られます。項目の削除は、確認後にアプリ内のコピーを削除し、アプリ内のゴミ箱はありません。「写真」のオリジナルや、以前に書き出したコピーは削除しません。

7. パターン・復旧フレーズ・グリッド

歯車アイコンから「保管庫の設定」を開きます。パターンの変更は、現在のパターンを確認し、新しいものを2回入力します。忘れた場合はロック画面の「保管庫を復旧」で、その保管庫の復旧フレーズを使って新しいパターンを設定します。誤った入力が続くと待機時間が発生します。

復旧フレーズの生成・変更は「復旧」の項目から行います。新しいフレーズを外部に保存して再入力し、現在のパターンで確認してください。生成フレーズをおすすめします。変更すると、ローカル復旧では古いフレーズが直ちに無効になります。既存のiCloudバックアップには、次回のバックアップ完了後に反映されます。過去に書き出したファイルは、常に作成時のフレーズが必要です。

「パターングリッド」はすべての保管庫をまとめて変更します。サイズを選び、保管庫ごとに古いパターンを確認してから、重複しない新しいパターンを2回描きます。生体認証を有効にした保管庫がある場合は、その認証も必要です。最後に確認して保存します。キャンセルでは元の設定を保持し、保存が成功すると開いている保管庫の画面をロックします。

復旧フレーズはバックアップではありません。パターンのリセットは、端末に残っているファイルを開くためのものです。削除したファイルの復元には、保存済みバックアップも必要です。

8. iCloudにバックアップする

  1. 所有する保管庫で、「設定 → 暗号化iCloudバックアップ」を開きます。
  2. その保管庫の復旧フレーズを入力し、iCloudバックアップを有効にします。
  3. 通信とiCloudの空き容量を確保し、保管庫を開いたまま最後に完了したバックアップの日付が表示されるのを待ちます。
  4. 機種変更やアプリ削除の前は、「今すぐバックアップ」で最新のコピーを保存します。中断した送信は、保管庫を開き直して再試行します。

保管庫ごとに個別の有効化が必要です。最新の完了したコピー1つを保持し、過去の世代は保持しません。フォアグラウンドで動作し、端末間の双方向同期ではありません。

「無効にしてクラウドバックアップを削除」は、今後のバックアップを停止し、設定済みクラウドコピーの削除を要求します。ローカルファイルは残ります。削除が保留中の場合は、同じiCloudアカウントで通信できる状態にし、再試行を完了させてください。

9. iCloudから復元する

  1. バックアップを所有するApple Accountにサインインします。
  2. 初期設定、ロック画面、またはバックアップ設定で「iCloudから復元」を選びます。
  3. 日付でバックアップを選び、最新の完了した送信に有効なフレーズを入力します。
  4. バックアップを開き、重複しないローカル保管庫名と、新しいパターンを設定します。
  5. 復元後は新しい復旧フレーズを設定し、今後のバックアップが必要なら再度有効にします。

復元は新しい保管庫を作成し、既存の保管庫を上書きしません。名前も暗号化されるため、最初の選択一覧は日付で区別します。無料版の上限はインストール前に確認され、上限を超えるバックアップの一部を黙って切り捨てることはありません。

パターンだけでは削除したメディアを復元できません。完了済みバックアップがなければ、復旧フレーズだけでも復元できません。

10. 暗号化バックアップファイルを使う

「設定 → ファイルバックアップ → バックアップファイルを書き出す」で復旧フレーズを入力し、.patternbackupファイルを「ファイル」経由で保存します。ファイルとフレーズは別々に保管してください。iCloud Driveなどに保存する場合は、そのサービスのアップロード完了を待ちます。

バックアップファイルは、その時点のスナップショットです。後の変更を含めるには再度書き出します。復元は「バックアップファイルを読み込む」からアーカイブを選び、作成時のフレーズを入力して新しい保管庫を設定します。現在の復旧フレーズを変更しても、過去のアーカイブは書き換わりません。

11. 保管庫を共有する・共有を受け取る

共有を作成する

  1. PatternVault Proで、所有する保管庫の「設定 → 共有」を開きます。
  2. 必要に応じて相手のラベル、有効期限、最大閲覧回数、書き出しの許可、キャプチャ検知によるロックを設定します。
  3. 「共有フレーズを作成」を選び、アップロードの完了を待ちます。
  4. 共有フレーズをコピーし、意図した相手だけに送ります。解除パターンや復旧フレーズとは別のものです。表示画面を離れると、同じフレーズは再表示されません。

共有を受け取る

初期設定、ロック画面、または設定の「共有保管庫に参加」を選びます。iCloudにサインインした状態で共有フレーズを入力し、ローカルの名前とパターンを決めます。最初に受け取ったApple Accountが受信者になります。同じアカウントは、元の共有フレーズで再度読み込めます。

受信は無料で、所有する保管庫の上限には含まれません。読み取り専用で、開くには通信が必要です。閲覧中も定期的に権限を確認します。所有者が保管庫を開いている間に更新を送信し、受信者は開き直したときに利用可能な版を受け取ります。

アクセスを管理・終了する

所有者の「共有」設定で更新を送ったり、アクセスを取り消したりします。取り消しはiCloudに届くと有効になります。保留中の取り消しが終わるまで、アプリを削除しないでください。閲覧回数はローカルのインストールごとに数えるため、削除や再インストールでリセットされる場合があります。キャプチャによるロックは検知後の対応であり、最初のスクリーンショットや外部カメラを防げません。既に書き出されたコピーはPatternVaultでは制御できません。

12. Face ID・Touch IDとダミー保管庫

設定で「Face IDとダミー保管庫」、またはTouch ID端末の同等の項目を開きます。別の既存保管庫をダミーに選び、生体認証を有効にし、パターンと生体認証による確認を進めます。

パターンで保護対象の保管庫を選んだ後、生体認証が成功すると開きます。端末のパスコードは代わりになりません。認証の失敗、拒否、キャンセル、利用不可の場合は、選んだダミーが表示されます。システムによる中断ではロック状態を維持します。

ダミーとして開いた状態でもメディアを利用できますが、保管庫の設定や新規保管庫の作成はできません。完全な操作には、そのダミー自身のパターンで開いてください。ダミーが削除されている場合、認証失敗では開きません。生体認証の失敗だけでは、強要対策は作動しません。

13. 強要対策は、有効にする前に確認する

他の保管庫へのアクセスが変わります。別途保存した利用可能なバックアップがない、かけがえのないデータで有効化や動作確認をしないでください。

「強要対策用保管庫を使用」は、現在の保管庫の既存パターンを作動用に設定します。説明を確認して同意し、現在のパターンで設定します。この時点では作動しません。

その後、この作動用パターンで解除すると、次の処理を行います。

  • 選択したダミー、またはダミーがない場合は作動元の保管庫を残します。別のダミーを残す場合、作動元もアクセスを失います。
  • その他すべてのローカル保管庫の認証情報を削除します。ファイルはディスク上に残りますが、古いパターンや復旧フレーズではPatternVaultで開けません。
  • 残した保管庫の復旧フレーズを新しく生成します。設定の「新しい復旧フレーズを保存」で外部に保存してください。
  • そのインストールでのクラウドバックアップ、共有、手動バックアップを停止します。自分が作成した共有の取り消しを予約します。過去の個人用クラウドバックアップや、別途書き出したファイルは消去しません。

機能をオフにしても、失われたアクセスの復元やバックアップの再有効化は行いません。独立した利用可能なバックアップの復元は別の操作です。設定画面内でのパターン確認では作動しません。この機能は安全な消去や、アプリ内データの存在が発見されないことを保証するものではありません。

14. アイコン・言語を変える

「設定 → アプリ設定 → アプリアイコン」でデザインを選びます。「クラシック」で標準に戻します。その端末のすべての保管庫に共通して適用され、アクセス権やインストール済みアプリの名前は変わりません。

ランチャーに別の名前を付ける場合は、アイコン選択画面のホーム画面名に関するショートカット作成ガイドを利用してください。選択した画像で、Appleの「ショートカット」に「Appを開く → PatternVault」のランチャーを作成する手順です。別のショートカットが追加されるもので、元のアプリの改名・非表示・削除ではありません。

英語、日本語、韓国語、フランス語、ドイツ語、イタリア語、簡体字中国語に対応します。利用できる場合は、端末の「設定」でアプリの言語を変更します。自分で付けた名前、ファイル名、フレーズの単語は翻訳されません。

15. 購入、削除、お問い合わせ

保管庫の設定で「PatternVault Pro」を開き、購入または購入の復元を行います。買い切りで、通常購入と特別オファーの機能は同じです。元のApple Accountで購入を復元してください。保管庫のメディアは別途バックアップから復元します。

保管庫の削除には、名前と現在のパターンが必要です。ローカルの内容と認証情報を削除し、所有する保管庫の場合は設定済みクラウドバックアップと自分の共有の削除も要求します。他のローカル保管庫、写真のオリジナル、書き出したファイルは残ります。受信した保管庫はローカルコピーだけを削除します。

PatternVaultを削除すると、ローカル保管庫とインストール用の鍵が失われます。「Appを取り除く」ではデータを保持します。削除前に復元できるバックアップを確認し、希望するクラウド削除を完了させてください。よくある質問をご覧いただくか、[サポートメールアドレス — 未定]までご連絡ください。アプリ・OSのバージョンとエラーメッセージを添え、秘密のフレーズは送らないでください。
