1. 첫 보관함 만들기

  1. 안내를 진행하거나 건너뛰고 새 보관함 만들기를 선택합니다. 기존 백업·초대가 있으면 복원·참여를 선택하세요.
  2. 3 × 3, 4 × 4 또는 5 × 5 그리드와 이름을 정합니다.
  3. 4개 이상 서로 다른 점을 쓰는 패턴을 두 번 그립니다. 통과한 점은 자동 포함되며 같은 동작에서 점을 재사용할 수 없습니다.
  4. 권장되는 자동 생성 20단어 문구 또는 8단어 이상·40자 이상의 사용자 문구를 메모에 저장하거나 문구 복사로 앱 밖에 저장합니다.
  5. 전체 문구를 다시 입력하고 외부 저장을 확인합니다. 구매 제안은 닫고 무료로 계속할 수 있습니다.
이 기기 없이도 접근할 수 있는 곳에 문구를 보관하세요. 앱 전환은 미완료 설정을 메모리에 유지하지만 프로세스가 끝나면 잃을 수 있습니다.

iOS/iPadOS 26.2 이상이 필요합니다.

2. 보관함 열기와 전환

각 등록 패턴은 해당 보관함을 엽니다. 라이브러리 상단의 새 보관함으로 새 이름과 고유 패턴을 두 번 설정하세요. 모르는 패턴을 그린다고 자동 생성되지는 않습니다.

전환하려면 잠근 뒤 다른 패턴을 그립니다. 백그라운드로 이동하면 잠기고 앱 전환 화면은 콘텐츠를 가립니다. 반복 오류에는 앱을 다시 열어도 유지되는 대기 시간이 적용됩니다. 무료 한도는 본인 보관함 3개, 각각 5개 항목이며 받은 보관함은 제외됩니다.

3. 사진·동영상·메모·문서 추가

대상 보관함이나 폴더에서 추가 메뉴를 여세요. 사진 선택기의 미디어, 비공개 카메라, 메모, 파일 앱의 문서를 추가할 수 있습니다. 미리보기를 지원하지 않는 문서도 저장·내보낼 수 있습니다. 가져오기는 사본을 만들고 원본은 남깁니다.

사진 원본 삭제는 성공적인 가져오기 뒤 별도 선택과 시스템 확인이 필요하며 iCloud 사진에 연결된 기기에 영향을 줄 수 있습니다. 최근 삭제된 항목은 비우지 않습니다. Live Photo는 현재 정지 이미지만 가져오고 원본을 자동 삭제하지 않습니다. 움직임이 필요하면 원본을 보관하세요.

4. 비공개 카메라

  1. 추가 메뉴의 카메라를 열고 권한을 허용합니다. 소리 있는 동영상에는 마이크 권한이 필요합니다.
  2. 사진·동영상과 사용 가능한 카메라를 선택해 촬영합니다.
  3. 사용은 현재 보관함·폴더에 저장합니다. 다시 촬영, 취소 또는 백그라운드 이동은 미확정 초안을 버립니다.

사진 앱에 자동 사본은 저장하지 않습니다. 줄 그어진 스피커 옵션은 호환 카메라의 ARKit 프레임으로 무음 사진을 만들므로 일반 고해상도 사진보다 세부 품질이 낮을 수 있습니다. 동영상 녹음을 끄는 기능은 아닙니다. 시스템 촬영·검토 화면은 어둡게 보일 수 있습니다.

5. 검색·필터·정리

  • 검색: 현재 폴더·라이브러리의 항목명·파일명을 선택한 필터와 함께 검색합니다. 문서 본문은 검색하지 않습니다. 폴더 변경이나 추가 시 검색어를 지웁니다.
  • 정렬: 화살표 아이콘에서 가져온 날짜, 이름, 파일 날짜 또는 큰/작은 크기 순을 선택합니다. 원본 메타데이터가 없으면 대체 날짜를 씁니다.
  • 필터: 전체, 사진, 동영상, 메모, 문서입니다.
  • 선택: 원 안의 체크 아이콘으로 개별·전체 선택, 이동, 내보내기, 삭제를 하고 다시 눌러 종료합니다.
  • 폴더: 만들기, 이름·색 변경, 삭제, 항목 이동을 할 수 있습니다. 폴더만 삭제하면 파일은 남습니다.

넓은 iPad에는 폴더 사이드바가 있습니다. 사진 확대·넘기기, 기본 동영상 재생을 지원하며 영상을 떠나거나 앱을 배경으로 보내면 재생을 멈춥니다.

6. 내보내기와 삭제

항목을 선택해 공유 시트로 파일 앱 등 원하는 대상으로 내보냅니다. 메타데이터가 남을 수 있는 일반 사본이며 암호화된 PatternVault 백업은 아닙니다. 암호화 아카이브는 파일 백업을 쓰세요.

받은 보관함의 내보내기는 소유자 허용이 필요합니다. 삭제 확인 후 앱 사본을 지우며 내부 휴지통은 없습니다. 사진 원본이나 이전 내보내기 파일은 지우지 않습니다.

7. 패턴·복구 문구·그리드

보관함 설정에서 패턴을 바꾸려면 현재 패턴과 새 패턴 두 번을 확인합니다. 잊었다면 잠금 화면의 보관함 복구에서 복구 문구로 새 패턴을 설정하세요. 반복 오류에는 대기 시간이 있습니다.

문구 변경 시 새 문구를 외부에 저장하고 반복 입력한 뒤 현재 패턴을 확인합니다. 이전 문구는 로컬 복구에서 즉시 무효입니다. 기존 iCloud 백업은 다음 백업 완료까지 이전 문구를 쓰며, 내보낸 백업 파일은 항상 생성 당시 문구가 필요합니다.

그리드 변경은 모든 보관함에 적용됩니다. 각각 기존 패턴과 새 고유 패턴 두 번을 확인하고, 생체 인증을 쓰는 보관함이 있으면 인증도 수행합니다. 검토 후 저장하세요. 취소하면 그대로이며 성공하면 열린 보관함 창이 잠깁니다.

복구는 백업을 대신하지 않습니다. 삭제된 파일을 되찾으려면 사용 가능한 백업도 필요합니다.

8. iCloud 백업

  1. 본인 보관함에서 설정의 암호화된 iCloud 백업을 엽니다.
  2. 복구 문구를 입력하고 백업을 활성화합니다.
  3. 연결과 여유 공간을 확보하고 보관함을 열어 두어 마지막 완료 날짜를 확인합니다.
  4. 기기 교체 전에 새 백업을 실행하세요. 중단되면 다시 열어 재시도합니다.

보관함마다 별도 활성화하며 최근 완료본 하나만 유지합니다. 이력 관리나 양방향 동기화가 아닙니다. 끄고 클라우드 백업 삭제는 클라우드 삭제를 요청하고 로컬 파일을 남깁니다. 보류된 작업은 원래 iCloud 계정과 연결이 필요합니다.

9. iCloud에서 복원

  1. 백업을 소유한 Apple Account에 로그인합니다.
  2. 초기 설정, 잠금 화면 또는 백업 설정에서 iCloud에서 복원을 선택합니다.
  3. 날짜로 백업을 선택하고 마지막 완료 업로드에 맞는 문구를 입력합니다.
  4. 고유한 로컬 이름과 새 패턴을 설정합니다.
  5. 복원 후 새 복구 문구를 만들고 원하면 향후 백업을 다시 활성화합니다.

기존 보관함을 덮어쓰지 않고 새로 만듭니다. 이름이 암호화되어 처음 목록에는 날짜가 표시됩니다. 무료 한도는 설치 전에 확인하며 큰 백업을 임의로 잘라 복원하지 않습니다. 패턴이나 문구만으로는 삭제된 파일을 되살리지 못합니다.

10. 암호화 백업 파일

파일 백업 → 백업 파일 내보내기에서 복구 문구를 입력하고 .patternbackup 파일을 저장합니다. 파일과 문구는 따로 보관하고, iCloud Drive 등 클라우드에 저장하면 해당 업로드가 끝날 때까지 기다리세요.

파일은 그 시점의 사본입니다. 변경 사항은 다시 내보내야 합니다. 백업 파일 가져오기에서 파일과 생성 당시 문구를 선택한 뒤 새 보관함을 만드세요. 현재 문구 변경은 기존 파일을 다시 쓰지 않습니다.

11. 보관함 공유·받기

Pro에서 본인 보관함 설정의 공유를 여세요. 수신자 표시 이름, 만료, 최대 열기, 내보내기 허용, 캡처 시 잠금을 선택할 수 있습니다. 공유 문구 만들기 후 업로드를 기다리고 의도한 사람에게 비공개로 보내세요. 화면을 떠나면 문구를 다시 표시하지 않습니다. 복구 문구와는 다릅니다.

수신자는 공유 보관함 참여에서 iCloud에 로그인한 상태로 문구를 입력하고 로컬 이름·패턴을 정합니다. 최초 Apple Account가 수신자가 되며 같은 문구로 다시 가져올 수 있습니다. 받기는 무료이며 본인 보관함 한도에 포함되지 않습니다.

읽기 전용이며 열기 전과 이용 중 온라인 검증을 합니다. 소유자는 보관함이 열린 동안 변경 내용을 보내고, 수신자는 다시 열 때 갱신합니다.

공유 설정에서 접근을 취소하고 iCloud 작업이 끝날 때까지 앱을 유지하세요. 열기 횟수는 설치별로 기록되어 삭제·재설치로 초기화될 수 있습니다. 캡처 후 잠금은 최초 스크린샷이나 외부 카메라를 막지 못하며, 이미 내보낸 사본을 통제하지 못합니다.

12. 생체 인증과 위장 보관함

Face ID 및 위장 보관함 또는 Touch ID 설정에서 다른 기존 보관함을 고르고 보호를 켠 뒤 패턴·생체 인증 확인을 따릅니다. 패턴이 대상 보관함을 선택하고 생체 인증 성공 시 엽니다. 기기 암호로 대신할 수 없습니다.

실패·거절·취소·사용 불가 시 선택한 위장 보관함을 열며 시스템 중단은 잠금 상태를 유지합니다. 위장 세션에서는 미디어 작업만 가능하고 설정·새 보관함 생성은 막습니다. 위장 보관함 자체 패턴으로 열면 전체 권한을 씁니다. 위장 보관함이 삭제되었다면 실패 시 계속 잠깁니다. 생체 인증 실패는 강압 대응을 작동시키지 않습니다.

13. 강압 대응의 영향

독립적인 사용 가능 백업 없이 대체 불가능한 데이터로 활성화하거나 시험하지 마세요.

강압 대응 보관함 사용은 설명과 동의·패턴 확인 후 현재 패턴을 작동용으로 설정합니다. 설정 즉시 작동하지는 않으며, 나중에 해당 패턴으로 열면 다음 일이 발생합니다.

  • 선택한 위장 보관함, 없으면 작동한 보관함을 남깁니다. 위장이 다른 보관함이면 작동 원본도 접근을 잃습니다.
  • 나머지 모든 로컬 보관함 인증 정보를 제거합니다. 파일이 디스크에 남아도 이전 패턴·복구 문구로 열지 못합니다.
  • 남은 보관함에 새 복구 문구를 만듭니다. 새 복구 문구 저장으로 외부에 보관하세요.
  • 해당 설치의 클라우드·수동 백업과 공유를 중지하고 소유한 공유 취소를 예약합니다. 이전 개인 클라우드 백업과 별도 내보내기 파일은 지우지 않습니다.

비활성화해도 접근이나 백업 기능이 되돌아오지 않습니다. 독립 백업 복원은 별도 작업입니다. 설정 안에서 패턴을 확인하는 것은 작동시키지 않습니다. 안전한 완전 삭제나 데이터 발견 방지 보장이 아닙니다.

14. 아이콘과 언어

앱 설정 → 앱 아이콘에서 디자인을 선택합니다. Classic은 기본 아이콘으로 돌아갑니다. 기기의 모든 보관함에 적용되며 접근이나 설치 앱 이름은 바뀌지 않습니다.

홈 화면 이름 안내는 Apple 단축어의 “앱 열기 → PatternVault”에 선택한 그림과 이름을 적용한 별도 실행 아이콘을 만듭니다. 원래 앱을 개명·숨김·삭제하지 않습니다.

지원 언어는 영어, 일본어, 한국어, 프랑스어, 독일어, 이탈리아어, 중국어 간체입니다. 가능한 경우 기기 설정에서 앱 언어를 변경하세요. 사용자의 이름·파일명·문구 단어는 번역하지 않습니다.

15. 구매·삭제·문의

설정의 PatternVault Pro에서 일회성 구매 또는 원래 Apple Account의 구매 복원을 선택합니다. 일반·할인 구매의 기능은 같으며 구매 복원은 미디어 복원이 아닙니다.

보관함 삭제에는 이름과 현재 패턴이 필요합니다. 로컬 파일·인증 정보를 제거하고 본인 보관함이면 설정된 클라우드 백업과 공유 삭제도 요청합니다. 다른 보관함·사진 원본·내보내기는 남고, 받은 보관함은 로컬 사본만 지웁니다.

앱 삭제는 로컬 데이터와 설치 키를 지우며 앱 정리하기는 데이터를 남깁니다. 먼저 백업을 확인하고 필요한 클라우드 삭제를 끝내세요. 자주 묻는 질문 또는 [지원 이메일 — 미정]로 문의하되 버전·오류를 보내고 비밀 문구는 보내지 마세요.
